HORAS EXTRAS PRO — GARDY | VERSÃO 11 — PERFIS INDIVIDUAIS

O QUE MUDOU
- Campo para identificar o funcionário e abrir seu perfil.
- Cada perfil tem lançamentos e configurações salariais separados no mesmo navegador/aparelho.
- Salário começa em branco para cada perfil novo, evitando herdar o valor de outra pessoa.
- CSV, backup JSON e PDF passam a identificar o funcionário no nome do arquivo; o PDF também mostra o nome no relatório.
- Os dados antigos deste navegador são migrados para o perfil ativo na primeira abertura desta versão.
- Cache do aplicativo atualizado para v11.

COMO PUBLICAR NO GITHUB PELO CELULAR
1. Faça backup JSON dos seus registros antes de atualizar, por segurança.
2. Abra o repositório GitHub e substitua os arquivos da raiz pelos arquivos deste ZIP.
3. Envie também a pasta icons com os dois ícones.
4. Faça Commit changes na branch main.
5. Aguarde o GitHub Pages publicar. Depois abra o site no Safari e atualize a página.
6. Se estiver usando o app instalado na tela inicial, abra o site no Safari uma vez para atualizar o cache e depois reabra o app.

COMO CADA FUNCIONÁRIO USA
1. Cada pessoa abre o mesmo link no próprio celular.
2. Digita seu nome em “Perfil do funcionário” e toca em “Abrir meu perfil”.
3. Preenche o próprio salário, divisor, jornada e demais configurações.
4. Registra as jornadas normalmente.
5. Faz backup JSON periodicamente e guarda em local seguro.

IMPORTANTE — LIMITAÇÕES DESTA VERSÃO
- É um controle individual local: não há login, senha, banco de dados central ou sincronização entre aparelhos.
- Em aparelhos diferentes, cada funcionário terá seus próprios dados locais, mesmo usando o mesmo link.
- No mesmo aparelho, os perfis são separados pelo nome, mas não são protegidos por senha; alguém com acesso ao aparelho/navegador pode abrir os perfis.
- Limpar os dados do navegador ou trocar de aparelho pode apagar os registros locais. Use backup JSON para transferir/restaurar.
- Não substitui o sistema oficial de ponto nem a conferência do holerite.
