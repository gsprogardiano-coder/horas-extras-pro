HORAS EXTRAS PRO — PACOTE PARA GITHUB PAGES

1) Crie um repositório público chamado horas-extras-pro no GitHub.
2) Envie TODOS os arquivos desta pasta para a raiz do repositório:
   index.html, manifest.webmanifest, sw.js, .nojekyll e a pasta icons.
3) No repositório, abra Settings > Pages.
4) Em Build and deployment, escolha Deploy from a branch.
5) Selecione branch main e pasta /(root), depois Save.
6) Aguarde a publicação. O endereço será:
   https://SEU-USUARIO.github.io/horas-extras-pro/

PWA:
- iPhone: abra o endereço no Safari > Compartilhar > Adicionar à Tela de Início.
- Android: abra no Chrome > menu > Instalar aplicativo / Adicionar à tela inicial.

DADOS:
- Registros ficam no armazenamento local do navegador.
- Use Backup JSON para transferir dados manualmente entre dispositivos.
- Não há sincronização em nuvem nem login nesta versão.

IMPORTANTE:
O repositório e o site do GitHub Pages são públicos no plano gratuito.
Não coloque dados pessoais ou documentos no repositório.
